# GreenRoof India 🌱

An educational project exploring how green roofs may help reduce urban heat in Indian cities.

## Features
- Live temperature, humidity, and precipitation data
- Interactive map of selected Indian cities
- Seven-day weather forecast
- City comparison dashboard
- Illustrative green-roof prioritization score

## Technology Stack
- HTML, CSS, JavaScript
- Open-Meteo Weather API
- Leaflet map library
- Chart.js

## How to Run
Download or clone this repository and open `index.html` in a modern web browser with an internet connection.

## Limitations
The prioritization score is illustrative, not a validated scientific model. Selected city weather readings do not represent entire states or long-term climate conditions.

## Purpose
Created as an Environmental Studies project on green roofs and urban heat.
